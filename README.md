# Keçi Oyunu

iPad için sonsuz koşu oyunu. Keçi köyden kaçıyor ve önüne çıkan herkese tosluyor.

## Nasıl oynanır

| Dokunuş | Hareket |
|---|---|
| Ekranın sol yarısı | Zıpla (havadayken bir kez daha: çift zıplama) |
| Ekranın sağ yarısı | Tosla |

Klavyede: `Boşluk` / `↑` zıplar, `→` / `X` toslar, `Esc` duraklatır.

- **Köylü** 10, **Turist** 15, **Bekçi** 30 puan (bekçiye 2 kez toslamak gerekir).
- Art arda toslamalar kombo yapar: puan x2, x3 … x5'e kadar katlanır.
- Toslamadan birine çarparsan ya da **taşa** veya **çite** takılırsan 1 can gider. Bunların üstünden zıpla.
- Havada süzülen **ot** 1 can geri verir. 3 can bitince oyun biter.
- Oyun zamanla hızlanır. Rekor cihazda saklanır.

## iPad'de çalıştırma

Oyun tek bir dosyadan oluşur: `index.html`. Kurulum gerekmez.

1. Dosyayı bir web adresinde yayınla (ör. GitHub Pages: Settings → Pages → `master` dalı).
2. iPad'de Safari ile aç.
3. Paylaş → **Ana Ekrana Ekle**. Böylece tam ekran, uygulama gibi açılır.

En iyi deneyim yatay tutuşta, ama dikey tutuşta da oynanabilir.
